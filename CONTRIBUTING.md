# Contributing to Project Monolith 🤝

Thank you for looking at the architecture! Project Monolith is an open-source decentralized physical ecosystem. Since we are balancing high-end unibody machining with low-latency software links, we welcome help from all engineering disciplines.

## Active Engineering Roadmap

* We need help translating the `circuit_schematic_guide.txt` connections into a single, compact, multi-layer Gerber PCB design file.
* Optimization required for reducing the footprints of the MX1508 modules and transistor networks to sit underneath the main launcher floor deck.

### ⚙️ Mechanical / CAD Modeling
* Looking for 3D modeling files (.STEP, .IGS, or .STL) for the 6061-T6 aluminum unibody shell matching the 4.0" x 3.0" x 2.25" outer volume constraints.
* Design provisions needed for the internal nitrile rubber shock-isolation gasket mounting slots.

### 🎮 Software & UI Deployment
* Implementation of the WebSocket framework inside a mobile game engine layout (Godot/Unity).
* Setting up the 2D pixel asset databases to respond to the incoming JSON card scanning matrices.
